# Nova Geração Roleplay — Site (Desenvolvimento)

Projeto criado com React + Vite + Tailwind CSS. Use este guia para executar o site localmente.

Requisitos
- Node.js 18+ e npm 9+ (ou versão compatível)

Instalação
```bash
cd "c:\Users\Usuario\Desktop\SITE NG"
npm install
```

Executar em desenvolvimento
```bash
npx vite
# ou
npm run dev
```

A aplicação estará disponível em http://localhost:3000/

Observações
- Coloque a sua imagem de logo na raiz do projeto como `logo.png` (já detectada).
- Imagens de seção (hero, about, cards) devem ser colocadas em `src/assets/` com os nomes indicados em `src/assets/README.md`.
- Para construir a versão de produção execute `npm run build`.
